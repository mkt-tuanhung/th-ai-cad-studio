## 5. Build, chạy, đóng gói

```bash
# UI (cần Node; Vite dev server ở cổng 5173)
cd ui && npm install && npm run dev            # dev
npm run build                                  # bản phát hành (KHÔNG có móc QA)
VITE_QA_HOOKS=1 npm run build                  # bản cho e2e cần window.__thcad

# Native (Homebrew: qtbase qtwebchannel qtwebengine opencascade llama.cpp libredwg; CMake ≥3.24, Ninja)
cd native && cmake -S . -B build -G Ninja && cmake --build build   # bước build cũng gói ui/dist vào app
# App dev: native/build/app/MD CAD AI STUDIO.app

# Đóng gói macOS
cd native && ./package_macos.sh && ./packaging/macos/make_dmg.sh  # dmgbuild venv ở build/dmgvenv

# Windows: chỉ qua CI (vcpkg ggml[vulkan], whisper.cpp Vulkan + CPU variants, Inno Setup)
gh workflow run windows-installer --ref main
```

**Biến môi trường hữu ích:**
- `THCAD_QA=1`: chế độ kiểm thử, dùng hồ sơ web riêng `thcad-qa`.
- `THCAD_SCRIPT=<file.js>`: chạy kịch bản trong app.
- `THCAD_SELFTEST=1`: chạy tự kiểm tra.
- `THCAD_MODELS_DIR`: chọn thư mục mô hình.
- `THCAD_MODEL_MIRROR`: máy chủ giả lập để tải mô hình (dùng cho QA).
- `THCAD_SPLASH=0`: bỏ màn intro.
- `THCAD_UI_URL`: trỏ UI tới Vite.
- `THCAD_DWG_SAMPLE` và `THCAD_PICK_DIR`: cho e2e_batch.
- `THCAD_PDF_OUT`, `THCAD_DWG_OUT`: ghi file mà không mở hộp thoại.

- **C++** `ctest` (native/build): đạt. **TypeScript** `tsc --noEmit`: sạch.

**Những điểm dễ vấp khi chạy kiểm thử:**
- e2e cần `window.__thcad` phải dùng bản build `VITE_QA_HOOKS=1`. **Build lại không có cờ này trước khi đóng gói DMG.**
- `e2e_voice` cần `QTWEBENGINE_DISABLE_SANDBOX=1` và `QTWEBENGINE_CHROMIUM_FLAGS="--use-fake-device-for-media-stream --use-file-for-fake-audio-capture=<qa/fixtures/voice/vi_window_SYNTHETIC.wav>"`.
- macOS không có lệnh `timeout`. Dùng vòng lặp chờ "E2E DONE" như script mẫu `rune2e.sh` (xem mục 12).
- Cổng 8765 trên máy này đã bị chương trình khác chiếm, máy chủ giả lập dùng **18765**.
- Chụp cửa sổ: dùng `screencapture -l<CGWindowID>` (lấy ID qua JXA `CGWindowListCopyWindowInfo`). Quyền ghi màn hình **đã được cấp**.
- Màn hình tắt thì Chromium ngừng vẽ, ảnh chụp ra trắng: chạy QA kèm `caffeinate -u -t N &`.

## 10. Việc đang mở (theo thứ tự ưu tiên)

1. **Dựng 3D từ bản vẽ 2D.** Người dùng chọn làm cả hai, **B trước** (2026-10-12), ưu tiên nội thất, xây dựng, máy CNC. **B xong** (`QA_FROM_CAD.md`), **A xong** (2026-10-13, `QA_ROUTE_FROM_CAD.md`), **nút "1 lệnh: làm hết từ bản vẽ" xong** (2026-10-13, `QA_AUTO.md`). Việc tiếp theo: kiểm B trên DWG nhà thật; A: ghép với tuyến khảo sát có toạ độ, tách đắp máy / thủ công. Mục tiêu sản phẩm người dùng nêu 2026-10-13: "chỉ cần 1 lệnh là hệ thống tự làm việc" (kỹ sư không phải ngồi vẽ CAD, dựng 3D). Hai hướng:
   - **A. Hạ tầng (kênh, đường):** DWG trắc dọc + trắc ngang theo lý trình → corridor 3D, mặt đất và mặt thiết kế, khối lượng đào đắp. Câu hỏi "mặt cắt ngang và dọc" nghiêng về hướng này. Có thể tận dụng `ui/src/civil/*`, `scene3d.ts` và primitive mesh của native.
   - **B. Nhà:** DWG mặt bằng + mặt cắt → tường, cửa, sàn trong BIM → 3D và IFC.
   - **Nguyên tắc:** code đọc hình học; AI chỉ giúp phân loại layer / đối tượng; mọi kết quả qua bước đề xuất và duyệt.
2. Cho AI **tạo cấu kiện mới** trong BIM / MEP (tường, ống…) theo lệnh, vẫn qua đề xuất và duyệt. Chưa được yêu cầu chính thức, chỉ là đề xuất.
3. Thử nút tải mô hình trên máy Windows thật (cần người dùng có máy).
4. Sau này: PWA giám sát và ra lệnh từ xa (module riêng); ký mã (nếu người dùng chịu phí).

## 12. Script tiện ích QA (có trong repo)

- `qa/tools/rune2e.sh <script.js> <timeout-s> [ENV=VAL…]`: chạy một kịch bản e2e trong app bản dev và in số PASS/FAIL. Ví dụ: `qa/tools/rune2e.sh $PWD/native/app/resources/e2e_cad.js 300`.
- `qa/tools/model_mirror.py`: máy chủ giả lập tải mô hình, hỗ trợ HTTP Range. Ba chế độ: `MODE=ok` (bình thường), `drop` (cắt kết nối ở `DROP_AT`), `corrupt` (trả file `.bad`). `THROTTLE` để giới hạn tốc độ. Dùng kèm `THCAD_MODEL_MIRROR=http://127.0.0.1:18765`.
- `e2e_batch` cần một file DWG mẫu thật trong `THCAD_DWG_SAMPLE`, và `THCAD_PICK_DIR` là thư mục để ghi kết quả.
